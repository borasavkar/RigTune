# RigTune

Ekran kartına, monitöre ve yüklü oyunlara göre sürücü uygulaması (AMD Adrenalin, NVIDIA App, Intel Graphics Software) ve oyun içi ayar önerileri veren masaüstü uygulaması. AMD'de Adrenalin'deki mevcut ayarları okur ve değiştirilmesi gerekenleri gösterir; hiçbir ayarı kendisi değiştirmez.

| Klasör / dosya | İçerik |
|---|---|
| `desktop/` | Masaüstü uygulaması (Electron). Kullanım ve komutlar: [desktop/README.md](desktop/README.md) |
| `index.html` | İlk sürüm: tarayıcıda açılan tek dosyalık sayfa (RX 9070 XT için Adrenalin önerileri) |
| `adrenalin-ayar.artifact.html` | Aynı sayfanın claude.ai'de yayınlanan biçimi |
| `docs/` | Geliştirme sırasındaki konuşmanın özeti ve kararlar |
| `CLAUDE.md` | Proje notları: sistem, kod yapısı, araştırma bulguları, açık işler |
